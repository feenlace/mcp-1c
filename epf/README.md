# Подключение к 1С через внешнюю обработку

`MCPConnector.epf` подключает Community к открытой 1С без установки расширения или HTTP-сервиса. MCP работает на компьютере, где открыт клиент 1С или браузер, а запросы к данным выполняются в 1С от имени текущего пользователя и с его правами. Обработка поддерживает чтение конфигурации и метаданных, структуры форм и хранения, выполнение SELECT-запросов, проверку синтаксиса, подсчёт доступных записей и ограниченное чтение журнала регистрации при наличии прав администратора. Недоступные операции возвращают сообщение об ограничении.

Скачайте `MCPConnector.epf` отдельно в разделе [Releases](../../releases/latest). Если клиент 1С открыт в сеансе RDP, MCP должен работать внутри этого сеанса на удалённой машине. Облачный AI-клиент без локального MCP не может напрямую подключиться к обработке; публичный ретранслятор не предоставляется.

## Настройка

Настройте AI-клиент на запуск Community MCP с отдельным путём для файла кода в приватном каталоге:

```text
mcp-1c --epf-listen 127.0.0.1:9090 --epf-token-file /absolute/private/pairing-token
```

Эти параметры заменяют настройки HTTP-подключения; не указывайте одновременно `--base`, `--user` или `--password`. При запуске MCP создаёт файл с одноразовым кодом. Откройте `MCPConnector.epf` в нужной базе, укажите порт и введите код из второй строки файла. Код действует пять минут и используется один раз; установленная сессия продолжает работать после истечения этого срока. Держите 1С, обработку и MCP открытыми.

Для следующего подключения используйте новый код, созданный при остановке сессии или повторном запуске MCP. Не передавайте код или данные сессии другим людям и не помещайте файл в репозиторий. Если файл недоступен, проверьте права на приватный каталог и запустите MCP снова. Существующий файл другого формата не перезаписывается: укажите новый отдельный путь.

При работе через браузер дополнительно укажите точный Origin публикации 1С, например:

```text
--epf-web-origin http://127.0.0.1:59342
```

Подставьте Origin страницы 1С из адресной строки. Разрешён один точный HTTPS Origin или локальный HTTP Origin без пути; он распространяется на весь указанный Origin. Браузер может запретить удалённой HTTPS-странице обращаться к локальному HTTP MCP. В этом случае используйте клиент 1С на той же машине, где запущен MCP.

Веб-клиент обработки использует API платформы 1С 8.3.21.1302 или новее. Совместимость расширения и минимальная поддерживаемая версия продукта остаются 8.3.14; работа обработки на самой платформе 8.3.14 не проверена.

### Ожидание ответа

В форме «Ожидание ответа, сек.» задаёт положительное целое число секунд, включая очередь. По умолчанию 30. Поле доступно до подключения, значение сохраняется в открытой форме после остановки и применяется при следующем подключении. Произвольного верхнего предела нет, требуется представимость длительности и срока хранения результата сервером. Старый сервер работает с новым полем при значении 30, для другого значения нужен совместимый сервер.

Сервер подтверждает действующее ожидание транспорта по умолчанию. Явно заданные `--request-timeout` или `MCP_1C_REQUEST_TIMEOUT` могут уменьшить его, это ограничение остаётся в состоянии формы после опроса. Неявные пять минут HTTP-клиента EPF не ограничивают это ожидание. HTTP и polling сохраняют прежние настройки.

Это ожидание не отменяет выполнение в 1С и не продлевает разрешение на начало операции. Задание должно начаться за первые 30 секунд либо до более раннего срока допуска. Уже начатая операция может завершиться после окончания ожидания. Не повторяйте автоматически операцию с неизвестным результатом, используйте наблюдение исходной операции.

Отдельные операции сохраняют собственные сроки. `code_execute` использует явные 1–120 секунд, включая переопределение общего CLI-предела. `query_package` и `object_diff` сохраняют сроки вызывающей стороны и конечную длительность worker, `quality` сохраняет свой срок операции, отчёты — двухминутный срок вызова. Значение 600 для обычного запроса или журнала не продлевает эти ограничения и нативное выполнение.
