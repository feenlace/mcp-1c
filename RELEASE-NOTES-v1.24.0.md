## mcp-1c Community v1.24.0

### Подключение через внешнюю обработку 1С

Теперь AI-клиент может работать с уже открытой 1С через внешнюю обработку EPF. MCP запускается на компьютере пользователя рядом с клиентом 1С; запросы к данным выполняются на сервере 1С от имени текущего пользователя и с его правами. Устанавливать дополнительный HTTP-сервис или CFE для этого способа подключения не нужно — серверу 1С также не требуется обращаться к компьютеру пользователя.

Настройте AI-клиент на запуск `mcp-1c` с параметрами `--epf-listen 127.0.0.1:9090` и `--epf-token-file` с отдельным приватным путём. Откройте EPF в 1С и введите одноразовый код из файла. Эти параметры заменяют настройки HTTP-подключения: не задавайте вместе с ними `--base`, пользователя или пароль. Код действует пять минут и используется один раз; установленная сессия не завершается по этому таймеру. Клиент 1С, EPF и MCP должны оставаться открытыми.

Для браузерной публикации задайте точный Origin через `--epf-web-origin`. Политики браузера могут не разрешить удалённой HTTPS-странице обращаться к локальному MCP; такая схема не гарантируется. Инструкция и пример настройки: [`epf/README.md`](epf/README.md).

### Более точные ответы инструментов

Неизвестный или `null`-фильтр журнала регистрации теперь приводит к явному отказу, а не к чтению без фильтра. Паспорт окружения показывает версию EPF-коннектора отдельно от версии расширения 1С. Если структура формы восстановлена из выгрузки, результат больше не сопровождается устаревшим предупреждением.

### Расширение 1С

`MCP_HTTPService.cfe` версии 0.4.10 не изменилось. При подключении через EPF устанавливать его не требуется; существующее HTTP-подключение продолжает работать.

### Установка расширения 1С через Конфигуратор

Для HTTP-подключения скачайте `MCP_HTTPService.cfe`. В Конфигураторе откройте «Конфигурация → Расширения конфигурации», добавьте расширение из файла, убедитесь, что оно активно, и обновите конфигурацию базы данных (F7). Расширение рассчитано на 1С:Предприятие 8.3.14 и выше.
