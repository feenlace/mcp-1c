## Community v1.24.0

### Подключение к открытой 1С

Теперь можно подключить AI-ассистента к открытой 1С через внешнюю обработку — без установки расширения и отдельного HTTP-сервиса для MCP. Работа выполняется с правами текущего пользователя 1С.

**`MCPConnector.epf` поставляется отдельным файлом.** Скачайте его, откройте в 1С и настройте подключение по [инструкции](https://github.com/feenlace/mcp-1c/blob/v1.24.0/epf/README.md).

MCP запускается на компьютере с клиентом 1С, поэтому удалённому серверу базы не требуется доступ к компьютеру пользователя. При работе через RDP MCP должен запускаться на удалённой машине вместе с клиентом 1С. Для веб-клиента потребуется настройка адреса публикации; подключение также зависит от ограничений браузера.

### Все инструменты Community доступны через EPF

Через EPF поддерживаются **все 11 инструментов Community для работы с подключённой 1С**:

- Получение метаданных, сведений о конфигурации, объектах, подсистемах и окружении.
- Выполнение и проверка запросов, подсчёт записей и просмотр структуры хранения.
- Получение сведений об основной форме.
- Чтение журнала регистрации.

Запросы выполняются **только на чтение — SELECT/ВЫБРАТЬ**, с правами текущего пользователя. Проверка синтаксиса относится к запросам, а не к произвольному коду встроенного языка. Для чтения журнала регистрации необходимо право «Администрирование».

EPF показывает имя и заголовок основной формы. Элементы, команды и обработчики можно получить из существующей выгрузки конфигурации, подключив её к MCP через `--dump`. Инструменты для файлов и выгрузок продолжают работать независимо от подключения к базе.

### Более точные ответы

Некорректные фильтры журнала регистрации теперь вызывают явную ошибку вместо чтения без указанного фильтра. Паспорт окружения отдельно показывает версию EPF-коннектора. При получении структуры формы из выгрузки больше не показывается устаревшее предупреждение.

### Расширение 1С осталось прежним

В комплект входит **`MCP_HTTPService.cfe` версии 0.4.10**, без изменений относительно v1.23.0. **Новых регистров и других объектов хранения нет.** Если эта версия уже установлена, повторно применять расширение не нужно.

Для подключения через EPF расширение не требуется. Существующий способ подключения через HTTP продолжает работать.

Для первой установки CFE откройте «Конфигурация → Расширения конфигурации», добавьте файл расширения и обновите конфигурацию базы. Минимальная версия платформы и режим совместимости расширения остаются **8.3.14**.
