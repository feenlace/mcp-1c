## mcp-1c Community v1.24.0

### Подключение к открытой 1С

Теперь можно подключить AI-клиент к открытой 1С через внешнюю обработку без установки расширения или HTTP-сервиса. Работа выполняется от имени текущего пользователя 1С с его правами. MCP запускается рядом с клиентом 1С на компьютере пользователя, поэтому серверу 1С не нужно подключаться к этому компьютеру.

Скачайте отдельный файл `MCPConnector.epf` и откройте его в 1С. Для начала работы настройте локальный MCP по [инструкции подключения](https://github.com/feenlace/mcp-1c/blob/v1.24.0/epf/README.md). Если 1С открыта через RDP, MCP должен работать в том же удалённом сеансе. Для браузерного клиента необходимо указать адрес публикации; ограничения браузера могут препятствовать подключению из удалённой HTTPS-публикации.

### Более точные ответы

Журнал регистрации сообщает об ошибке в неизвестном фильтре или значении `null` вместо чтения без него. Паспорт окружения отдельно показывает версию EPF-коннектора. При восстановлении структуры формы из выгрузки устаревшее предупреждение больше не показывается.

### Расширение 1С

`MCP_HTTPService.cfe` версии 0.4.10 не изменилось: новых регистров и других объектов хранения нет. Если эта версия уже установлена, повторно обновлять расширение не нужно. Для подключения через EPF оно не требуется; существующее HTTP-подключение продолжает работать.

Для установки расширения откройте в Конфигураторе «Конфигурация → Расширения конфигурации», добавьте скачанный `MCP_HTTPService.cfe`, убедитесь, что он активен, и обновите конфигурацию базы данных (F7). Минимальная версия 1С и режим совместимости расширения остаются 8.3.14.
