### Настройка ожидания ответа 1С

В обработке подключения EPF добавлена настройка времени ожидания ответа. По умолчанию оно составляет 30 секунд. Для длительных запросов можно указать большее значение.

После подключения отображается применённое время ожидания ответа по умолчанию с учётом явного ограничения сервера. У отдельных операций могут быть собственные сроки. Внешний MCP-клиент также может ограничивать время ожидания своим таймаутом. Сообщения об истечении ожидания показывают фактически сработавший таймаут.

Окончание ожидания не отменяет уже начатую операцию в 1С. Её результат может остаться неизвестным.

Чтобы использовать новую настройку в Открытой редакции, обновите MCP-сервер и обработку EPF.
